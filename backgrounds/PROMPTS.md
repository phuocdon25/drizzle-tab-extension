# Prompts for generating backgrounds — copy & run

How to use:
1. Copy the **Gemini / ChatGPT** block (or the **Midjourney** line) of the theme you want.
2. Download the image, rename it to the file name shown next to the theme, and copy it into the `backgrounds/` folder.
3. Reload the extension in `chrome://extensions` → open a new tab → pick that theme.

Every prompt includes layout requirements: the upper center stays calm (clock + search bar), the right side has
fewer details (Todo panel), no text/logo. The light/dark tone of each image matches its theme so the UI stays readable.

If the image has text or a watermark: generate it again and add `absolutely no text, no letters, no signature`.

## (Optional) Turning the image into a moving video

Generate the image first, then use an image-to-video tool (Runway, Kling, Pika, Luma…) with the prompt:

```
subtle seamless loop, gentle ambient motion, static camera, no zoom, no camera movement
```

Export a 5–10s `.mp4`, name it e.g. `autumn-pond.mp4`, and change `"file"` in `index.json` to match.
